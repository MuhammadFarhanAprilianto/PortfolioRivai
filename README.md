# Portfolio Muhamad Rivai

> **Quality Control Specialist | Plate Welder 3G SMAW | Store Leader & Marketing | Visual Communication Designer**

Website portofolio interaktif dan modern yang dibangun menggunakan **Next.js 14 (App Router)**, **Tailwind CSS**, dan **Framer Motion**.

---

## 🚀 Fitur Utama
- **Estetika Modern & Dark Mode:** Background pure black `#000000` dengan subtle white dot-grid.
- **Bilingual Switcher:** Dukungan penuh bahasa Indonesia (`ID`) dan Inggris (`EN`).
- **Interactive Bento Grid:** Ringkasan profil, matriks keahlian 3D bevel, dan rekam jejak karier.
- **Showcase Portofolio & Modal Preview:** Filter proyek & sertifikat terverifikasi resmi (BNSP, AWS, Kimia Farma, Pstore).
- **Responsive di Semua Perangkat:** Mobile (iOS/Android), Tablet, Laptop, dan Desktop 4K.

---

## 🛠️ Menjalankan di Lokal

```bash
# Install dependensi
npm install

# Jalankan server pengembangan
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) pada browser Anda.
